# XtendedMenu Privacy Policy

**Effective Date:** August 5, 2026

XtendedMenu is a Windows utility designed to enhance your workflow. This policy explains our commitment to your privacy.

## 1. Data Collection
XtendedMenu operates entirely locally on your Windows machine. It does not collect, store, or transmit any personal information, file names, or system data to external servers.

## 2. System Integration
The application requires administrative privileges only to modify Registry keys necessary for adding options to the Windows context menu. These modifications are performed locally and can be reverted using the application settings.

## 3. No Tracking
There is no telemetry, analytics, or background tracking implemented in XtendedMenu.
